# Known Limitations

This repository is an experimental research prototype.

Current limitations:

- Not a production input method.
- Toy lexicon and toy corpora only.
- Current CUDA backend uses brute-force candidate-rank estimation.
- Current optimizer is early-stage.
- No large-scale benchmark yet.
- No user study yet.
- No validated human-friendly code table yet.
- Python and CUDA evaluators need formal alignment tests.
- Current sample results are smoke tests, not real-world typing claims.

Data limitations:

- Do not commit copyrighted corpora, private chat logs, or paid publication text.
- Use public/open corpora or local aggregate statistics for future benchmarks.
