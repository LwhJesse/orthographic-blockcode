# 当前限制

本仓库是实验性研究原型。

当前限制：

- 不是生产级输入法。
- 目前只有 toy 词典和 toy 语料。
- 当前 CUDA 后端使用 brute-force candidate-rank 估计。
- 当前优化器仍处于早期阶段。
- 尚无大规模 benchmark。
- 尚无用户实验。
- 尚无已验证的人类友好码表。
- Python 和 CUDA 评估器需要正式对齐测试。
- 当前 sample 结果是 smoke test，不是现实输入性能声明。

数据限制：

- 不要提交受版权保护的语料、私人聊天记录或付费出版物文本。
- 后续 benchmark 应使用公开/开放语料，或使用本地聚合统计。
